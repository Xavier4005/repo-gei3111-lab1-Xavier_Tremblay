Une issue doit servir à identifier un problème. Premièrement Le titre doit être clair et concis. Deuxièmement, la description doit être précise pour que les autres membres puissent facilement retrouver où se situe l'erreur. Troisièmement, il est bon d'assigné les membres concerner à l'issue pour qu'il soit mis au courant.
